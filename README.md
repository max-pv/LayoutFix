# LayoutFix

A World of Warcraft addon that fixes chat typed in the wrong keyboard layout. US English pairs with Russian, Ukrainian, Greek, Hebrew, Arabic, and Thai.

## Installation

1. **[Download LayoutFix ZIP](https://github.com/max-pv/LayoutFix/archive/refs/heads/main.zip)** and unzip it.
2. Move the inner **LayoutFix** folder into your WoW client's `Interface/AddOns/` folder. You should have `Interface/AddOns/LayoutFix/LayoutFix.toc`.
3. Enable **LayoutFix** on the character screen. In chat, press **Shift+Tab** on 3.3.5a or **F8** on Classic Era and Retail.

Pick your layout under **Options → AddOns → LayoutFix**. See [development notes](DEVELOPMENT.md) for compatibility and tests.
